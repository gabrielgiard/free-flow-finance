FreeFlow Finance — Start Here

Two ways to get your site online. Pick one. You don't need to know how to code.

What's in the folder

docs/The website as separate files. This is what GitHub uses in Option B.

Option A — Get it online in 2 minutes
Fastest · no account needed

Netlify Drop

Best if you just want a link to send people today.

  1. Rename the file. Find FreeFlow-Finance.html and rename it to exactly index.html
  2. Go to app.netlify.com/drop
  3. Drag that one file onto the page.
  4. Done. You get a link straight away. Copy it and send it to anyone.
Prices won't update by themselves with this option, and the charts stay empty. Everything else works perfectly. You can always do Option B later.
Option B — The proper setup
15 minutes · free forever

GitHub Pages

Takes longer, but your code is visible to others — which matters for college applications and internships — and prices can update by themselves.

  1. Make an account at github.com/signup
  2. Create a repository. Click the + in the top right, then New repository. Name it freeflow-finance. Choose Public. Don't tick any boxes. Click Create repository.
  3. Upload your files. On the empty page, click the link "uploading an existing file". Open your unzipped folder, select everything inside it (Cmd+A on Mac, Ctrl+A on Windows), and drag it in. Then click Commit changes at the bottom.
  4. Turn on the website. Click Settings at the top, then Pages in the left menu. Under Source pick Deploy from a branch. Set Branch to main and folder to /docs. Click Save.
  5. Wait one minute, then refresh that page. Your link appears in a green box: https://yourname.github.io/freeflow-finance/
Seeing a 404? Wait two more minutes and refresh — the first build is slow. If it's still there, go back to step 4 and check the folder says /docs and not / (root).
Optional — Make prices update themselves
About 12 minutes · only after Option B

Automatic daily updates

Skip this if you like. Your site works perfectly without it — the prices just stay where they are until you change them yourself.

What you're actually doing, in plain English: your site needs somewhere to get today's share prices. A company called Finnhub gives them away free. They hand you a key — a long random string that works like a password, so they know it's you asking. You give that key to GitHub, GitHub keeps it secret, and once a day it fetches the prices for you.

Part 1 · Get your key (3 min)

  1. Go to finnhub.io and sign up. It's free and only needs an email address.
  2. Check your email and confirm your account if they ask you to.
  3. Once you're logged in, look for your API key on the dashboard. It's a long jumble of letters and numbers, something like cq3f8h9r01qmbc...
  4. Copy it. Then leave that tab open in case you need it again.
Never paste this key into a file. Anyone who sees it can use up your allowance. It only ever goes in the one place in Part 2.

Part 2 · Give the key to GitHub (3 min)

  1. Open your freeflow-finance page on GitHub.
  2. Click Settings in the row of tabs along the top.
  3. In the menu down the left side, find Secrets and variables and click it, then click Actions underneath it.
  4. Click the green New repository secret button.
  5. In the Name box, type exactly: FINNHUB_API_KEY
    All capitals, with underscores. No spaces. This has to match perfectly.
  6. In the Secret box, paste your key from Part 1.
  7. Click Add secret.
You should now see FINNHUB_API_KEY in a list. You won't be able to read the key itself ever again — that's not a mistake, that's the whole point of it being secret.

Part 3 · Add the instructions file (4 min)

  1. Click your repository name at the very top to get back to the main page.
  2. Click Add file, then Create new file.
  3. In the filename box at the top, type exactly:
    .github/workflows/update-prices.yml
    Watch what happens as you type each / — GitHub splits it into folders automatically. That's how you make a hidden folder without ever seeing one.
  4. On your computer, open SETUP-auto-price-updates.txt. Double-clicking it opens TextEdit on a Mac or Notepad on Windows.
  5. Select everything in it and copy. (Cmd+A then Cmd+C on Mac, Ctrl+A then Ctrl+C on Windows.)
  6. Paste it into the big empty box on GitHub.
  7. Scroll down and click the green Commit changes button.

Part 4 · Test it right now (2 min)

Don't wait until tomorrow to find out whether it worked.

  1. Click the Actions tab along the top of your repository.
  2. If it asks whether to enable workflows, click the green button to say yes.
  3. In the left menu, click Update prices and rebuild site.
  4. On the right, click Run workflow, then the green Run workflow button that appears.
  5. Wait about two minutes, then refresh the page.
Green tick — it worked. From now on it runs by itself every weekday evening after the US market closes, and your site updates without you touching anything.
Red X — click into it to see why. Nine times out of ten the secret name is slightly wrong. Go back to Part 2 and check it reads exactly FINNHUB_API_KEY, all capitals, underscores not spaces or dashes.
Nothing breaks if you get this wrong. Your website carries on working with the prices it already has. The worst case is that GitHub emails you to say a job failed — annoying, not damaging. You can switch it off any time under Actions.
If something looks wrong
The charts are empty

That's expected at first, and it's not broken. The site records one closing price each day it updates, so charts fill in over two to three weeks. Everything else — the valuations, models and comparisons — works right now.

I can't find the .github folder in my zip

You're not missing anything. Files starting with a dot are hidden by your computer. That's exactly why SETUP-auto-price-updates.txt exists — it's a visible copy of the only file you need from in there.

The site loads but is blank

The file docs/data.js probably didn't upload — it's the biggest file, about 360 KB. Open the docs folder on GitHub and check it's there. If not, upload just that one file on its own.

I want to add more companies

Open any file in the companies folder, copy an existing entry, and change the numbers. The README.md has a template with every field explained. If you're editing on GitHub directly, the site rebuilds itself about a minute after you commit.

Do I need to install Python?

No. Both options above work without installing anything. Python is only needed if you want to rebuild the site on your own computer rather than letting GitHub do it.

One thing worth keeping: the site carries a note saying it's an educational project and not investment advice. Leave it there. Real research firms carry longer ones — it makes you look more serious, not less.
